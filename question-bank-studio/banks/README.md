# 問題集フォルダー

問題集は、1つの問題集につき1つのフォルダーに分けて置きます。

| フォルダー | 内容 |
| --- | --- |
| `ccar-f-foundations/` | 内蔵の問題集「CCAR-F Foundations」（152問・英語／日本語／简体中文） |

- 内蔵の問題集は `index.html` から読み込まれます。新しい内蔵問題集を追加する場合は、同じ形でフォルダーを作り、`index.html` の `<script>` と `app.js` の読み込み処理を合わせて変更してください。
- JSON 形式の問題集は、フォルダーに置く必要はありません。取り込み画面（`import.html`）から取り込むと、ブラウザー内に保存され、練習画面の「問題集」から選べます。
- 取り込み用の JSON の書き方は、プロジェクト直下の `README.md` と取り込み画面の「ファイルの形式」を参照してください。
