# 逢考必过，超肠发挥

JSON形式の問題集を取り込んで練習できる、英語・日本語・简体中文対応のブラウザー練習アプリです。内蔵の問題集として「CCAR-F Foundations」を含みます。

## 起動方法

1. `index.html` をブラウザーで開きます。
2. 右上のボタンで英語／日本語／简体中文を切り替えます。「三言語」を選ぶと3言語を同時に対照表示します。
3. 領域を選択し、学習モードまたは模擬テストを開始します。

ビルドやパッケージのインストールは不要です。成績と言語設定はブラウザーの `localStorage` に保存されます。これはアプリのフォルダー内にあるファイルではなく、ブラウザーがサイトごとに管理する保存領域です。開発者ツール（F12）を開き、Application（Edge/Chrome）またはStorage（Firefox）→ Local Storage → このアプリのオリジンを選ぶと確認できます。進捗データは `ccarf-data` に、利用者一覧は `ccarf-profiles`、現在の問題集は `ccarf-active-bank`、表示言語は `ccarf-language` に保存されます。取り込んだ問題集は同じオリジンの IndexedDB（`ccarf-banks`）に保存されます。`file://` で直接開く場合、保存の扱いはブラウザーによって異なることがあります。

## 利用者（プロフィール）

画面上部の「利用者」で切り替えます。「+ 追加」で名前を付けて新しい利用者を作れます。学習の進捗、間違い問題ノート、お気に入り、模擬テストの最高点、途中保存したセットは利用者ごと、かつ問題集ごとに分けて保存されます。同じブラウザーを複数人で使う場合に便利です。利用者の削除は、その利用者の保存データもすべて消去します。

この保存先はブラウザーごとに別なので、別のパソコンやブラウザーの間で進捗は共有されません。

## 問題集の切り替えと取り込み

「問題集」で内蔵の「CCAR-F Foundations」と、取り込んだ問題集を切り替えます。「JSONを取り込む」で取り込み画面（`import.html`）を開きます。取り込み画面ではファイルを選ぶ（またはドラッグ＆ドロップする）と内容を確認でき、「保存して選択」を押すと、その問題集が練習画面で選ばれます。形式の説明とサンプルのダウンロードも取り込み画面にあります。取り込んだ問題集は、取り込み画面の一覧から、または練習画面の「問題集を削除」で消去できます（内蔵の問題集は削除できません）。

JSONの形式は次のとおりです。`prompt`、`options`、`explanation` は文字列か、`en` / `ja` / `zh` を持つオブジェクトで書けます。`en` は必須で、`ja` / `zh` は省略できます（省略時は英語を表示します）。

```json
{
  "name": "My practice set",
  "domains": [{ "id": "alpha", "en": "Alpha", "ja": "アルファ" }],
  "questions": [
    {
      "id": 1,
      "domain": "alpha",
      "category": "Alpha",
      "prompt": { "en": "Which option is correct?", "ja": "正しい選択肢はどれですか？" },
      "options": [{ "en": "No" }, { "en": "Yes", "ja": "はい" }, { "en": "Maybe" }],
      "answer": "B",
      "explanation": { "en": "Option B is correct." }
    }
  ]
}
```

- `id` は問題集の中で一意にしてください。進捗はこの `id` で管理されます。
- `domain` は領域のIDです。`domains` を省略した場合は `category` を領域名として自動で作られます。
- `answer` は正解の選択肢の文字（`"A"`、`"B"` など）か、0から始まる番号（`0` は最初の選択肢）で指定します。
- 選択肢は2つ以上必要です。形式が不正なファイルは、どの項目が問題かを示して取り込みを中止します。

## 内容


- 問題集から取り込んだ全152問（5領域）
- 全設問・選択肢・解説を英語／日本語／简体中文で表示
- 個別の言語切替と3言語の対照表示
- 即時フィードバック付き学習モード
- 1問90秒（10問の場合15分）の模擬テスト、採点と解説レビュー
- 参考PDFのカテゴリ構成を基にした領域別選択
- 選択肢を問題セットごとにランダム表示し、採点・解説・再開時も正解との対応を維持
- 学習モードまたは模擬テストの誤答を錯題本に保存し、3回正解すると自動的に削除
- 錯題本から特定の問題を直接開き、各問題を手動で削除、または一覧全体を消去
- 選択した領域から5・10・15・20問をランダム抽出して模擬テストを作成（問題数が足りない選択肢は無効化）
- 問題セットから戻るときに「保存して終了／保存しない／続ける」を選択し、保存した進捗は次回再開可能
- 利用者ごとに進捗を分けて保存（複数人で同じブラウザーを使用可能）
- JSON形式の問題集を取り込み、内蔵の問題集と切り替えて練習可能（問題集ごとに進捗を分けて保存）

英語原文はワークスペース内の抽出テキストから読み込み、カテゴリ・設問・選択肢・正解・解説をアプリデータとして登録しています。すべての設問、選択肢、解説に日本語・簡体字中国語の翻訳を用意しました。カテゴリ別の件数はClaude Code 36問、Prompt Engineering 27問、Tool Design / MCP 19問、Agentic Architecture 31問、Context Management / Reliability 39問です。

PDFのページ境界で選択肢が一つ欠けている設問（Q78）は、原文にある3選択肢のまま保持しています。インポートスクリプトは `tools/import_questions.py` にあり、抽出テキストを再変換できます。翻訳データは `banks/ccar-f-foundations/translations/` 内の分割JSON、統合版は `banks/ccar-f-foundations/translation-bank.js` です。翻訳を作り直す場合は `tools/build_translation_bank.py` を実行してください。

## GitHub Pages で公開する

1. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main`（または使うブランチ）・`/ (root)` にします。
2. 公開URLは `https://<ホスト>/pages/<ユーザー>/<リポジトリ名>/` の形式になります。アプリはすべて相対パスで読み込むため、そのまま動作します。
3. 進捗（做题记录、错题本、收藏、利用者、模拟测试の最高点）はブラウザーの `localStorage` と IndexedDB に保存されます。リポジトリを更新する必要はありません。ただし、保存はブラウザーごと・URLごとに分かれるため、別のブラウザーやパソコンでは進捗は見えません。ブラウザーのサイトデータを消去すると進捗も消えます。
